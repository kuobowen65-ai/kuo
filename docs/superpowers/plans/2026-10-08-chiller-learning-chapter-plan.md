# 冰水主機零基礎教材 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立一份以典型半導體晶圓廠為情境、可讓零基礎讀者學會填寫冰水主機參數、判斷安裝位置、比較常見品牌並理解系統影響的 Obsidian 教材。

**Architecture:** 教材採單一設備章節搭配一份知識庫入口。主章節由原理、參數表、填寫範例、安裝、品牌、系統影響、控制、驗收、維護及測驗構成；所有案例數值明確標示為教學假設，台積電內容只引用官方公開資料。

**Tech Stack:** Obsidian Markdown、SI 單位、公開官方網頁、AHRI 551/591、製造商官方型錄、PowerShell 文字檢查。

用「冰水主機不是把水變成冰，而是把冰水回水中的熱搬到冷卻水或室外空氣」作為核心概念。

- [ ] **Step 2: 解釋四大冷凍元件**

```text

```

說明中央公用設施或冰機房、冷卻水塔所在區域，以及設備基礎、吊運路徑、抽管空間、排水、通風、冷媒偵測、洩壓管、噪音與震動需求。

## Task 3: 建立可填寫參數表與完整範例

**Files:**
- Modify: `空調/基本資料/冰水主機.md`

- [ ] **Step 1: 建立空白參數表**

表格欄位固定為「項目、符號／英文、單位、誰提供、怎麼填、合理性檢查」，涵蓋基本識別、冷凍能力、冰水側、冷卻水側、壓縮機／冷媒、電氣、機械安裝及控制通訊。

- [ ] **Step 2: 建立 1,000 RT 教學案例**

採用水冷式離心主機，假設：

```text
蒸發器能力：1,000 RT = 3,516.9 kW
冰水溫度：12°C → 7°C，ΔT = 5 K
滿載 COP：6.50
冷卻水溫度：30°C → 35°C，ΔT = 5 K
```

- [ ] **Step 3: 計算並核對教學流量**

使用：

```text
冰水質量流量 = 3,516.9 ÷ (4.186 × 5) = 168.0 kg/s
冰水體積流量 ≈ 605 m³/h
主機輸入功率 = 3,516.9 ÷ 6.50 = 541.1 kW
冷凝器排熱量 = 3,516.9 + 541.1 = 4,058.0 kW
冷卻水質量流量 = 4,058.0 ÷ (4.186 × 5) = 193.9 kg/s
冷卻水體積流量 ≈ 698 m³/h
kW/RT = 3.5169 ÷ 6.50 = 0.541 kW/RT
```

教材必須註明這些是忽略密度細微差異的初步估算，正式選型以實際水性質、污垢係數、壓降、工況及原廠選型為準。

- [ ] **Step 4: 說明每個值從哪裡來**

把每個範例值標示為設計負荷、系統溫度條件、計算結果、製造商選型結果或現場量測值，防止把預估值誤填成保證值。

引用公開資料說明冰水系統包含主機、冰水泵、冷卻水泵、冷卻水塔、熱回收等附屬設備，單看主機效率不等於整個冷站最低耗能。
